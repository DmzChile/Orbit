Orbit 요청 #1 처리 결과 — 0.1.4
기준일: 2026-10-25 (Asia/Seoul)
요청: https://github.com/DmzChile/Orbit/issues/1
요청 ID: c46eb677-f9f1-4a64-86e9-738320b51333 (version 3)

기존 처리 절차: 있음.
AGENTS.md, docs/REQUIREMENTS.md, docs/EXTERNAL_CHATGPT.md의 요청 확인→스냅샷/규칙 해시→격리 작업→검증→PR→orbit-run:v1 결과 댓글 계약을 따른다.

구현:
- 긴 본문과 사이드바를 같은 남은 창 높이로 구성하고 각각 스크롤한다. 200% 확대의 이전 반응형 스타일 충돌을 수정했다.
- 새 안정 버전 감지 시 앱 상단과 설정에 업데이트를 알린다.
- 사용자가 다운로드와 재시작·설치를 각각 선택한다. 진행률, 연결/다운로드 오류와 재시도를 제공한다.
- 일반 종료 시 자동 설치하지 않는다. 설치 전 창 상태·보류 저장을 완료하고 데이터 잠금을 해제한다. 저장/설치 시작 실패 시 앱 상태를 복구한다.
- GitHub Releases의 NSIS exe/blockmap/latest.yml을 사용하는 고정 피드 및 검증 후 배포 workflow를 추가했다. 앱에 배포 토큰을 넣지 않는다.

검증 증거:
- 타입/코드 검사, 단위·통합 57개 통과.
- 기존 Windows E2E 6개 및 새 사이드바/확대/상단 알림/IPC 검사 통과.
- NSIS 설치 패키지 생성 성공. resources/app-update.yml의 owner/repo 고정 확인. 설치 파일 NotSigned.
- 실제 패키지 앱+실제 NSIS 바이트+임시 loopback 피드로 연결 오류, 잘못된 SHA-512 거부, 정상 다운로드와 체크섬 일치, 사용자 설치 선택 대기, 일반 종료 시 데이터 보존을 확인했다. fixture 메타데이터 버전 99.0.0은 테스트 전용이다. 설치 파일은 실행하지 않았다.

제한과 남은 검증:
- main은 조사 시 문서/디자인만 포함했다. 요청된 main 대상 PR에는 기존 미병합 앱 구현(5430955까지)도 포함된다. 이번 수정은 별도 커밋이다.
- 공개 릴리스는 조사 시 없었다. 이번 작업은 태그/공개 릴리스 발행이나 사용자의 앱 설치를 수행하지 않는다.
- 기존 0.1.3 이하에는 updater가 없으므로 updater 포함 버전을 처음 한 번 설치해야 한다. 그 이후 앱 내부 업데이트를 사용할 수 있다.
- 실제 두 공개 릴리스 간 업그레이드/rollback/설치·제거와 OS DPI·스크린리더 검증은 남아 있다. SHIP-01 전체는 진행 중이다.
- 실제 ChatGPT 예약 생성/실행이나 앱이 결과를 수신했다는 사실은 이 개발 세션에서 확인하지 않았다.
