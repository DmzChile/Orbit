# 구현 및 검증 현황

기준: 2026-10-25 Asia/Seoul · 요구사항 v1.1. 사용자가 승인한 외부 ChatGPT 예약·한국 RSS·공전 모션 변경을 요구사항과 수용 기준에 반영했다. 원본 HTML은 보존했다.

**전체 제품 완료 상태가 아니다.** 로컬 Windows 앱과 공급자/원격 실행기 코드를 구현했으며 실제 뉴스와 로컬 데이터, 배포 exe를 검증했다. 운영 자격증명·정책/runner·서명/업데이트 인프라는 제공되지 않았다. 코드 존재와 mock/실제 원격 실행을 구별한다.

상태는 `미구현 / 진행 중 / 검증됨 / 차단됨 / 명시적 보류`를 사용한다. 진행 중은 구현 코드가 있어도 전체 수용 시나리오 검증이 남은 경우이다. 검증됨에도 범위 제한을 아래에 함께 적었다.

## 실제 실행 증거

- Windows 11 x64 (OS build 26200), Node 24.21.0, Electron 45.0.0.
- `npm run typecheck`, `npm run lint`, `npm run build`: 통과.
- `npm test`: 45개 도메인/저장/공급자/보안/AI 도구/산출물·파일 통합 테스트 통과. 외부 API/AI 응답 mock은 테스트 파일과 이름으로 명시.
- Windows Electron E2E: 실제 오프라인 일정·드래그·키보드·메모·재시작·모션·확대, 반복 개별 수정·삭제 및 **실제 한국 공식 RSS 뉴스** 수집/검색/저장/참조 전달의 5개 E2E 통과 (공전 진행·시스템/앱 모션 감소 포함).
- `npm run package`: 실제 미서명 NSIS 생성. `npm run test:packaged`: 실제 0.1.2 배포 exe first screen **1385ms** 단일 측정, app.isPackaged=true. 반복 측정/다른 PC 성능 보장은 아님.
- 증거 파일은 재현 가능한 `test-results/`, `work-evidence/packaged-smoke.json`에 생성하며 고객 데이터처럼 커밋하지 않는다. CI는 검증 증거와 설치 파일을 artifact로 보관하도록 구성했다.
- 실제 OS display scale을 변경하지 않았다. Windows의 Chromium zoom 100/150/200%를 OS DPI 검증과 구별한다.

## 반드시 남은 작업

1. 대상 테스트 저장소와 앱 PAT·외부 ChatGPT 예약/권한을 연결한 뒤 실제 수동·예약 작업, PR, 업로드, 수신/다운로드, 중단 복구 검증(E2E-04/05/06). 기본 경로에는 GPT API 키가 필요하지 않다.
2. Alpha Vantage 종목·유료 지수 운영 응답 검증. 키를 코드나 채팅에 공유할 필요 없이 앱/저장소 secret UI에서 설정한다.
3. 설치·제거·업데이트/rollback, 실제 OS DPI/멀티 모니터·Windows 스크린리더·알림 권한·절전, drag60fps 검증.
4. 재실행 없는 만료 산출물 재발급은 미구현이다. UTF-8 파일 첨부와 실제 기록 기반 성공률/지연/재전송 집계는 구현·통합 검증했다. 서명/자동 업데이트는 인프라 설정 전 비활성이다.

## 0.1.1 변경 검증

- 사용자의 별도 ChatGPT 예약 전제와 한국 RSS 선택을 기술 결정0002에 기록했다. 새 요청은 외부 공급자이며 기존 요청/결과·저장 기사·로컬 데이터는 보존한다.
- RSS2MiB·DTD/ENTITY·기사 도메인/시각·dedup·같은 스냅샷24개 pagination·전송 중단·오프라인 테스트 통과. 실제 동아일보 공식 피드 E2E 통과.
- 외부 요청 publish/queue/clipboard가 API key·workflow/dispatch 없이 동작하는 mock GitHub 통합 테스트 통과. 실제 GitHub에 요청을 게시한 검증은 아니다.
- 신뢰 계정·다른 요청 사본·실패 검사 결과 거부와 cursor/추적 Issue 두 경로 검증 통과.
- Windows E2E5개 통과. 기존 디자인과 한국어/좁은 창 동작을 유지하면서 공전 진행 및 OS/앱 모션 감소 정지를 확인했다. 실제 OS DPI 변경과 스크린리더 감사는 계속 남아 있다.
- 실제0.1.1 packaged exe 실행 및 포함된 외부 예약 안내 확인 통과. 첫 화면2076ms 단일 측정으로2초 목표보다76ms 초과했으며 OPS-02는 진행 중이다. 설치 파일은 NotSigned이고 설치/제거 수명주기 검증은 남아 있다.
- 스키마1→2 마이그레이션과 원본 v1 백업을 검증했다. 이전 앱이 외부 공급자 데이터를 손상된 파일로 처리하지 않도록 미래 스키마로 보호한다.
- 외부 ChatGPT 예약은 이 개발 세션에서 생성하지 않았다. 사용자 관리 작업을 연결한 실제 E2E04~06은 남아 있다. 공개 push 없이 로컬 커밋으로 전달한다.

## 0.1.2 뉴스 그래픽 변경 검증

- 사용자가 이전 행성·위성 빛을 철회하고 제공한 이미지 2장을 실제 확인했다. 요구사항 1.4/UX-05와 기술 결정0003에 최신 시각 요구를 반영했다. 원본 HTML은 변경하지 않았다.
- 청록색 행성·표면 띠·대기, 기울어진 7개 궤도를 SVG로 구성했다. 선과 잔광은 동일 경로를 재사용한다. 별도 연결선·궤도·위성 점·육각형·위성 이름을 추가하지 않는다.
- 두 뉴스 시각 영역(오늘 카드/리더)에 같은 컴포넌트를 사용한다. 긴 실제 한국어 제목과 행성 간격을 시각 확인했다. 그림의 예시 기사·출처를 운영 데이터로 사용하지 않는다.
- typecheck/lint/build·기존 단위/통합45개·Windows E2E5개 통과. 새 모션 E2E는18프레임 중10개 초과의 서로 다른 stroke offset, 동일 궤도 참조, 금지된 위성/라벨 없음, OS/앱 모션 감소·좁은 창 텍스트의 카드 내부 배치를 확인한다.
- 실제 한국 RSS 수집 성공 상태에서 앱 화면52프레임을 촬영했고 서로 다른 이동값52개 및 그래픽 영역의 실제 픽셀 변화를 확인했다. 해당 촬영을 GIF 미리보기로 묶었다. 앱은 연속 공전하며 GIF는 촬영 구간을 반복하는 미리보기다.
