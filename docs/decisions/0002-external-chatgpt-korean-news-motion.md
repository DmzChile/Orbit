# 기술 결정0002 — 사용자 관리 ChatGPT 예약, 한국 RSS와 공전

예약/뉴스 채택, 행성 모션은 기술 결정0003으로 대체 · 2026-10-25 Asia/Seoul · 요구사항1.1 · NEWS-01~06 / AUTO-01~05 / RES-01 / UX-05~07

사용자가 ChatGPT 예약을 직접 작성해 GitHub에 접근하고 GPT API 키 없이 쓰겠다고 요청했다. 뉴스는 키 없는 한국 언론사 공식 RSS를 선택했다. 따라서 새 요청은 chatgpt-external 공급자로 저장한다. Orbit은 요청 Issue·예약 정의·고정 수동 큐를 전달하고, 외부 작업용 프롬프트를 로컬 clipboard로 복사한다. workflow 검사/dispatch나 OpenAI API 호출이 필요하지 않다. 외부 ChatGPT에서 예약을 생성/수정했다고 표시하지 않는다.

[공식 예약 문서](https://learn.chatgpt.com/docs/automations)를 실제 열어 GitHub/plugin 도구를 이용하는 사용자 설정 예약과 환경/권한 조건을 확인했다. 문서의 존재는 이 앱에 외부 예약 생성 API가 제공된다는 뜻이 아니다. 계정에서의 실제 실행·권한·모델·이용 한도는 사용자 설정 후 검증해야 한다. 앱이 ChatGPT 쿠키·세션을 재사용하거나 비공개 API를 호출하지 않는다.

결과 댓글의 run 스키마·ID와 수신/다운로드 경로는 유지한다. 기존 Actions 봇 전용 검증은 외부 모드에서 연결 계정과 명시적 추가 게시 계정 허용 목록으로 전환한다. 요청 ID/스냅샷/공급자/저장소가 맞고 실패한 검사를 성공으로 기록하지 않아야 한다. 댓글 작성자 검증은 외부 작업이 안전하게 실행되었다는 감사 증거를 대신하지 않는다. 이전 API worker는 ORBIT_API_WORKER_ENABLED=true일 때만 작동하고 chatgpt-external 요청은 건너뛴다. 이전 데이터/결과는 보존한다. 외부 공급자 enum을 이전 앱이 해석하지 못하므로 로컬 스키마를2로 올리고 v1→2 마이그레이션과 최초 원본 state.json.v1.backup을 보존한다. 이전 앱은 미래 스키마를 거부해 덮어쓰지 않으며 downgrade는 이전 백업을 별도 폴더로 복사해 수행한다.

[동아일보 공식 RSS](https://rss.donga.com/)는 키가 필요 없고 개인 비상업적 이용 조건이 명시되어 있어 개인 워크스페이스의 기본 공급자로 채택한다. total.xml의 제목·URL·게시 시각만 수집하고 전문/사진을 재배포하지 않는다. 외부 XML은2MiB 제한, DTD/ENTITY 거부, XML 검증, 안전한 기사 도메인·시각 검사 후 파싱한다. fast-xml-parser5.11.2(MIT)를 정확한 버전/lockfile로 고정하며 production 라이선스 고지를 생성한다. 24개 단위의 피드 스냅샷 페이지를 사용해 추가 로딩 사이 변경으로 기사를 건너뛰지 않는다. 실패하면 저장된 캐시를 유지한다.

행성의 기존 색·크기·궤도 배치를 유지한다. 같은6초 부유 그룹 안에 얇은 타원 궤도와 작은 빛을 배치하고 CSS offset-path/offset-distance로8초 연속 공전을 표현한다. 깊이 순서로 행성 뒤/앞을 지나며 시스템/앱 모션 감소에서는 부유·공전 모두 정지한다. 장식은 aria-hidden이며 진행/성공 상태를 나타내지 않는다. 코드 기반 그래픽으로 구현해 외부 이미지·새 이미지 라이선스가 필요하지 않다.
