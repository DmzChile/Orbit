# 0006 — 배너에서 확장되는 워크스페이스

날짜: 2026-10-26 · 기준 main: cb6e6e79d0618904946b9f2683006a9290c4186d

## 승인 범위

사용자는 `orbit-banner-motion.mp4`의 배너 → 확장 창 → 원래 배너로 돌아가는 GUI를 실제 앱에 구현하도록 요청했다. 최신 지시에서 기존 뉴스 배너의 행성과 공전하는 고리를 그대로 유지하도록 지정했다. 앞선 영상 요청의 사이드바 제거·커스텀 위젯 UI 일시 제외·7개 메뉴 배너 배치·테마 상속을 이번 실제 구현 범위로 적용한다. 문서의 종전 사이드바/위젯 UI 기준은 이 범위에서 대체되며 저장 데이터와 공급자 계약은 유지한다.

참조 영상: https://chatgpt.com/library?file_id=libfile_af6e3265476c8191a1383555dbb60617&account_id=personal

## 실제 구현 기준

디자인 폴더의 HTML 대신 `src/renderer/main.tsx`, `style.css`, `NewsSpotlight.tsx`, `Sculpture.tsx`를 확인했다. 사이드바는 App의 JSX, 페이지는 Calendar/News/Work/Settings 컴포넌트, 공전 시각은 Sculpture의 7개 SVG 경로와 기존 CSS에 구현되어 있다.

- `Sculpture.tsx`와 `style.css`는 변경하지 않는다. 행성 색·표면·7개 궤도의 형태, 같은 경로를 사용하는 잔광, 공전 속도 및 모션 감소 규칙을 그대로 재사용한다.
- 첫 화면을 뉴스·오늘·캘린더·자동화·결과함·내 공간·설정 및 연결 배너로 구성한다. 날짜·일정·요청·읽지 않은 결과 수는 실제 상태를 사용한다.
- 뉴스 배너는 기존 분야별 캐러셀·정치 필터·기사 선택·정지/재개 기능을 유지한다. 배너 허브가 비활성화되면 기사 자동 전환을 멈춘다.
- 기존 실제 뉴스·일정 CRUD·요청·결과·설정·업데이트 UI를 확장 창에 연결한다. 이 작업은 외부 공급자/인증/예약 실행 계약을 변경하지 않는다.
- 홈과 내 공간에서 커스텀 위젯 UI를 일시 제외한다. 보드/위젯 스키마, 저장 내용, 기존 도메인/서비스 구현은 삭제하지 않는다.

## 전환과 입력

추가 모션 라이브러리 없이 Electron의 same-document View Transition API를 사용한다. 배너와 창의 동일한 스냅샷 이름으로 위치와 크기를 보간하고, 뉴스 행성은 별도 스냅샷으로 연결한다. 새 창의 내용은 확장된 표면에 맞춰 나타나며 실제 입력 폼은 React 컴포넌트로 유지한다. 약 700ms로 열고 670ms로 닫으며 두 확장 창 사이의 이동은 320ms다.

공식 API 근거:

- https://developer.mozilla.org/en-US/docs/Web/API/Document/startViewTransition
- https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::view-transition-group

허브를 DOM에 유지해 스크롤과 원래 배너 위치를 보존한다. 확장 창이 열리면 허브는 inert/aria-hidden으로 입력과 접근성 탐색에서 제외한다. 방문한 페이지는 숨겨 보관하므로 일반적인 뒤로가기/재진입으로 작성 중인 일정·요청·뉴스 필터를 잃지 않는다. 날짜나 기사에 대한 명시적 새 진입은 해당 선택을 연다.

뒤로 버튼·Escape·Alt+왼쪽 화살표로 허브에 돌아가고 원래 배너 버튼으로 포커스를 복원한다. 열린 dialog의 Escape는 가로채지 않는다. 빠른 재이동/취소는 이전 전환을 skip하고 최신 요청만 DOM에 반영한다. OS 또는 앱 모션 감소, 숨겨진 문서, API 미지원에서는 즉시 이동하며 포커스와 기능을 유지한다. 창 크기 변경 중에는 진행 중인 전환을 종료하고 새 레이아웃을 사용한다.

## 검증 경계

기존 서비스·단위 테스트와 실제 Electron E2E의 사용자 여정을 배너 진입으로 갱신한다. 위젯 드래그 UI 검증은 최신 승인에 따라 일시 보류하며 저장된 위젯 내용이 삭제되지 않는지 확인한다. 추가 E2E는 실제 크기 보간, 양방향 복귀/포커스, 초안 유지, 전환 취소, 모션 감소/API 미지원, 작은 창 접근을 검사한다.

로컬 Linux 컨테이너는 Unix 도메인 소켓을 허용하지 않아 Electron의 process singleton 초기화 단계에서 실행이 차단되었다. 앱의 보안/단일 인스턴스 코드를 우회하지 않는다. 타입·린트·단위·빌드 검사와 Windows CI의 실제 Electron 검증을 구분해 보고한다. 실제 Windows OS DPI/스크린리더·서명/출시 수명주기 및 외부 ChatGPT 작업의 기존 검증 제한은 유지한다.
