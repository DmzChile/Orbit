# 기술 결정 0003 — 참고 이미지의 궤도와 잔광

채택 · 2026-10-25 Asia/Seoul · NEWS-03 / UX-01·05·06·08 / E2E-08

사용자가 이전 행성/위성 빛을 철회하고 두 장의 이미지를 제공했다. 첫 번째의 청록색 행성·비스듬히 겹친 타원·어두운 청색 카드와 두 번째의 길게 남는 자취를 기준으로 한다. 육각형·위성 이름·추가 연결선은 그리지 않는다. 첨부의 예시 기사 제목/출처를 운영 뉴스로 하드코딩하지 않는다. 원본 HTML은 보존하며 Figma를 직접 열었다고 주장하지 않는다.

새 Sculpture SVG는 참고의 중첩 궤도 7개를 경로로 정의한다. 각 궤도의 정적인 선과 이동 잔광은 동일 경로를 use로 재사용한다. 서로 다른 길이·투명도의 선 조각이 같은 선두에서 겹쳐 밝은 앞부분부터 긴 꼬리까지 서서히 옅어진다. 별도 궤도/위성/라벨은 없다. 행성 앞뒤를 나누어 차폐하고 11~27초의 느린 공전으로 반복한다. 행성의 대기·표면 띠는 정적 SVG 그라데이션/클리핑으로 그린다.

CSS stroke-dashoffset 애니메이션을 사용해 별도 타이머·React 프레임 갱신·외부 이미지/라이브러리 없이 구현한다. 장식은 aria-hidden이다. 시스템/앱 모션 감소 시 애니메이션과 잔광을 숨겨 정적 궤도/행성만 유지한다. 실제 뉴스·일정·외부 ChatGPT 연동·데이터 계약에는 변경이 없다.

검증은 typecheck/lint/test/build와 Windows Electron E2E의 실제 선 이동, 같은 경로 재사용, 모션 감소, 좁은 창·문자 오버플로를 포함한다. 실제 앱 화면과 모션 미리보기로 시각 확인하고 설치 패키지도 검증한다. 설치/제거·실제 OS DPI·스크린리더·외부 예약 실행은 기존 미완료 상태를 유지한다.
