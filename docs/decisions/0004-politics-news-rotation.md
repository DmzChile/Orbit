# 기술 결정 0004 — 정치 뉴스와 분야별 순환

채택 · 2026-10-25 Asia/Seoul · APP-03 / NEWS-01~05 / UX-06~08 / DATA-01

사용자가 정치 섹션과 메인 뉴스의 분야별 순환을 요청했다. 기존 카드·행성·궤도 SVG는 유지하고 본문과 분야/이전·다음/재생 제어만 교체한다. 원본 HTML의 카드 계층·스타일을 검토했으며 Figma를 직접 확인했다고 주장하지 않는다.

[동아일보 공식 RSS 안내](https://rss.donga.com/)를 실제 열어 정치(politics.xml)·의학과학(science.xml)·경제(economy.xml)·도서(book.xml) 링크와 개인 비상업적 이용 조건을 재확인했다. 전체(total.xml)와 이4개 피드 모두 실제 XML 응답50개를 확인했다. 제목에 정치 단어가 없어도 공식 정치 피드의 기사는 정치로 분류한다. 분야 메타데이터와 제목 키워드를 합치며 전문/사진은 계속 수집하지 않는다.

5개 피드를 병렬 수집하고 동일 ID의 분야를 합친다. 일부 실패는 경고를 반환하며 성공한 피드와 기존 캐시를 유지하고, 전부 실패하면 기존 데이터를 바꾸지 않는다. 기사 있는 분야별로1개씩 선택하는 순서를 사용해 한 분야가 처음24개를 독점하지 않도록 한다. 추가 로딩은 같은 스냅샷을 사용한다. 메인 순환도 같은 균형 정책을 적용하며 여러 분야에 걸친 기사 ID는 중복 표시하지 않는다. 빈 분야는 가짜 기사 대신 건너뛴다.

기본 자동 전환은8초이다. 수동 선택은 일시정지하며 재생으로 재개한다. 마우스 hover·키보드 focus·문서 숨김·화면 밖에서는 일시 중지한다. OS/앱 모션 감소에서는 자동 전환을 끄고 직접 넘기기를 제공한다. 자동 전환마다 스크린리더 알림을 반복하지 않으며 수동 선택만 상태 알림으로 읽는다. SVG는 유지해 뉴스가 바뀔 때 궤도 모션이 처음부터 다시 시작하지 않는다.

필터 변경 시 리더도 해당 목록의 기사로 맞춘다. 메인에서 기사 열기를 명시적으로 누르면 기존 필터를 초기화해 선택한 기사를 연다. 단순 메뉴 왕복에서는 필터/스크롤/선택 유지가 계속 적용된다.

정치 enum을 이전 앱이 읽지 못하므로 로컬 스키마를3으로 올린다.1/2 스키마의 일정/보드/요청/저장 기사는 보존하고 원본 버전 백업을 남긴다. 초기화 시 v1/v2 백업도 삭제한다. 원격 ChatGPT 요청/결과 계약과 운영 자격증명에는 변경이 없다.

검증은 정치 RSS 분류·부분 실패·페이지·중복/분야 균형 단위/통합, 스키마 이전/백업, Windows E2E의8초 순환·정지/재개·모션 감소·올바른 기사 열기와 실제 정치 뉴스 수집으로 구분한다. UI 테스트의 가상 시간과 fixture는 테스트에만 격리한다.
