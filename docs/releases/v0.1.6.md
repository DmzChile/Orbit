# Orbit 0.1.6

## 변경 사항

- 배너를 열거나 닫는 도중 화면이 반투명해지고 뒤쪽 허브가 비치던 문제를 수정했습니다.
- 배너 테마에 맞는 불투명한 전환 표면을 유지하고 페이드 시간을 조정했습니다. 화면 간 전환과 뉴스 행성의 전환 시간도 맞췄습니다.
- 기존 뉴스 행성·공전 궤도와 잔광은 그대로 유지합니다. 뒤로가기, 초안과 포커스 복원, 모션 감소 설정도 유지합니다.

## 업데이트

0.1.4 이상 설치 앱은 0.1.6과 설치 파일·blockmap·latest.yml이 공개되면 시작·정기 확인 또는 **설정 및 연결 → 업데이트 확인**에서 새 버전을 확인합니다. **업데이트 다운로드 → 재시작 및 설치**를 선택해 설치합니다. 다운로드와 설치는 사용자가 시작합니다.

0.1.3 이하는 updater가 없어 새 설치 파일을 직접 실행해야 합니다. Windows x64 설치 파일은 미서명입니다. 저장 스키마는 변경하지 않으며 일정·보드·설정 데이터를 유지합니다. 설치 전에 작성 중인 폼은 저장하세요.

실제 공개 상태는 [GitHub Releases](https://github.com/DmzChile/Orbit/releases)와 설치 파일·업데이트 명세를 확인하세요. 실제 사용자 PC에서의 프레임율과 공개 릴리스 간 설치 업그레이드는 별도 검증 대상입니다.
