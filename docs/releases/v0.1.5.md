# Orbit 0.1.5

7개 메뉴 배너가 각 작업 화면으로 확장되고, 뒤로가면 원래 배너로 돌아오는 GUI를 제공합니다.

- 뉴스·오늘·캘린더·자동화·결과함·내 공간·설정 및 연결을 배너로 구성했습니다.
- 확장과 축소는 부드럽게 이어지며, 작업 화면이 해당 배너의 테마를 이어받습니다.
- 뉴스의 기존 행성·7개 공전 궤도·잔광 그래픽과 움직임을 그대로 유지했습니다.
- 일반적인 배너 재진입 시 초안·필터·스크롤을 보존하고 키보드 포커스를 복원합니다. 명시적으로 새 요청을 만들면 새 초안을 엽니다.
- 시스템/앱 모션 감소, 빠른 뒤로가기, 좁은 창과 확대 화면을 지원합니다.
- 커스텀 위젯 UI는 일시 제외했으며 저장된 보드·위젯 데이터는 유지합니다.

## 업데이트

0.1.4 이상 설치 앱은 공개 릴리스에 같은 빌드의 설치 파일·blockmap·latest.yml이 게시되면 시작·정기 확인 또는 **설정 및 연결 → 업데이트 확인**에서 0.1.5를 감지합니다. 상단의 **업데이트 다운로드 → 재시작 및 설치**를 선택해 반영합니다. 자동 다운로드나 일반 종료 시 자동 설치는 하지 않습니다.

0.1.3 이하는 updater가 없어 새 설치 파일을 직접 실행해야 합니다. Windows x64 설치 파일은 미서명입니다. 이번 버전은 저장 스키마를 변경하지 않으며 일정·보드·설정 데이터를 유지합니다. 설치 전 작성 중인 폼은 저장하세요.

이 문서와 버전 커밋만으로 공개 배포를 의미하지 않습니다. 실제 업데이트 제공 여부는 [GitHub Releases](https://github.com/DmzChile/Orbit/releases)의 v0.1.5와 첨부 파일 3종으로 확인합니다.
